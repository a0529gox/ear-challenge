# 耳朵練習室

以 React、TypeScript、Vite 和 Tone.js 建立的音樂聽力練習網站。提供單音、音程與三和弦辨認，無須登入；設定和最近 10 筆練習紀錄保存在目前瀏覽器。

## 題型與難度

難度會依題型改變音域或考題範圍；音高範圍中的 C4、C3、C2 分別代表不同八度。

| 題型 | 初學 | 中階 | 進階 |
|---|---|---|---|
| 單音辨認 | 從 C2–B2、C3–B3、C4–B4、C5–B5、C6–B6 勾選一個或多個音域 | 同左 | 同左 |
| 音程辨認 | 6 種音程 | 11 種音程 | 12 種音程 |
| 三和弦辨認 | 四種三和弦性質，音域 C4–B4 | 四種三和弦性質，音域 C3–B5 | 四種三和弦性質，音域 C2–B6 |

- **單音辨認：** 可混選多個音域，題目從已選範圍抽取；答案為 12 個半音音名之一。
- **音程辨認：** 難度決定音程種類數。作答內容可選「音程名稱」（單選，練習相對音高）或「兩音音名」（多選，音名含八度）。
- **三和弦辨認：** 作答內容可選「和弦性質」（大三、小三、減三、增三）、「和弦音」（多選三個含八度的音名）或「只答根音」（單選）。和弦使用根位排列。
- **選項試聽：** 共用設定，開啟後點選答案會播放該選項代表的聲音；音名多選時每次只播放被點選的單一音，不會播放已選音組。

## 本機開發

需要 Node.js LTS 和 npm。

```bash
npm ci
npm run dev
```

## 驗證與建置

```bash
npm test
npm run lint
npm run build
```

## GitHub Pages 部署

repository 的 GitHub Pages Source 請設為 **GitHub Actions**。推送到 `main` 後，`.github/workflows/deploy.yml` 會建置網站並發布。Vite 在 GitHub Actions 建置時會使用 `/ear-challenge/` 子路徑；本機開發與預覽則使用 `/`。

首次使用時請在開始練習或播放按鈕上操作，以符合 iOS Safari 的音訊啟動限制。所有練習音訊均由瀏覽器即時合成。
